## 6. Scripts de Manutenção

### 6.1 Restart Semanal Docker

**Script:** `/opt/scripts/restart-docker.sh`
**Agendamento:** Domingos às 3:00 AM (cron)
**Log:** `/var/log/docker-restart.log`

**O que faz:**
1. Envia notificação Telegram: "🔄 Iniciado"
2. Para todos os containers graciosamente
3. Reinicia o serviço Docker
4. Aguarda Docker ficar pronto (até 60s)
5. Reinicia todos os containers
6. Aguarda 20s para health checks
7. Verifica quantos containers estão rodando
8. Envia notificação Telegram: "✅ Finalizado" ou "⚠️ Problemas"

**Fluxo:**
```
docker stop (todos) → systemctl restart docker → aguardar Docker → docker start (todos) → verificar → notificar
```

### 6.2 Limpeza de Execuções n8n

**Frequência:** Diária, 3:00 AM
**Comando:** `DELETE FROM execution_entity WHERE status = 'success' AND startedAt < now() - interval '7 days'`
**Log:** `/var/log/n8n-prune.log`

3. Cutover via `docker compose up -d` (schema migrado automaticamente)
4. **Regressão corrigida:** n8n 2.34.5 removeu `axios`/`cheerio` das deps bundled → reinstalados no volume (`/opt/apps/n8n/data/nodes/`): `axios@1.15.0` + `cheerio@1.0.0`
5. Validação ponta-a-ponta: WebSocket 459s estável, `require('axios')` e `require('cheerio')` OK

**Backups (rollback):**

- `Dockerfile.bak-pre-upgrade`, `docker-compose.yml.bak-pre-upgrade`, `.env.bak-pre-upgrade`

**Rollback:** `sed -i 's/n8n-ffmpeg:2.34.5/n8n-ffmpeg:2.17.5/' docker-compose.yml && docker compose up -d` + restaurar dump SQL.
